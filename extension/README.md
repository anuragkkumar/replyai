# ReplyAI Chrome Extension

AI-powered reply assistant for WhatsApp, Instagram, Discord, and Telegram.

## Installation Instructions

### Step 1: Download the Extension
You already have the `ReplyAI.zip` file.

### Step 2: Extract the ZIP
Extract the contents of `ReplyAI.zip` to a folder on your computer.

### Step 3: Open Chrome Extensions
1. Open Chrome or Edge browser
2. Navigate to `chrome://extensions` (Chrome) or `edge://extensions` (Edge)

### Step 4: Enable Developer Mode
Toggle the "Developer mode" switch in the top right corner.

### Step 5: Load the Extension
1. Click "Load unpacked"
2. Select the folder where you extracted ReplyAI
3. The extension should now appear in your extensions list

### Step 6: Pin the Extension (Optional)
Click the puzzle icon in your browser toolbar and pin ReplyAI for quick access.

## Usage

### Keyboard Shortcut
Press `Ctrl+Shift+A` (Windows/Linux) or `Cmd+Shift+A` (Mac) to quickly open ReplyAI.

### Supported Platforms
- WhatsApp Web (web.whatsapp.com)
- Instagram DMs (www.instagram.com)
- Discord (discord.com)
- Telegram Web (web.telegram.org)

### How to Use
1. Open one of the supported chat platforms
2. Open a conversation with some messages
3. Click the ReplyAI extension icon or press `Ctrl+Shift+A`
4. Select a tone (Flirty, Funny, Professional, Roast, Savage, or Custom)
5. Click "Generate Reply"
6. Copy the generated reply and paste it into your chat

## Features
- Automatically reads the last 6 messages for context
- 6 different reply tones
- Custom tone option for personalized replies
- Fast AI-powered generation using Groq's llama-3.3-70b-versatile
- Privacy-focused: No conversations are stored or logged

## Troubleshooting

### Extension not detecting context
- Make sure you're on a supported platform (WhatsApp Web, Instagram, Discord, or Telegram Web)
- Refresh the page and try again
- Make sure there are visible messages in the chat

### "Failed to connect to server" error
- Check your internet connection
- Make sure the backend server is running

### Rate limit reached
- The API is limited to 10 requests per minute
- Wait a moment and try again

## Privacy & Security
- Your conversations are never stored or logged
- All processing happens server-side with enterprise security
- The extension only reads chat context when you explicitly open it
- No data is sent to third parties
